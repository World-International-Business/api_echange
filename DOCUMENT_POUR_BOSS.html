🔑 Clé API (Authentification)

Cette clé doit être configurée dans l'application mobile. Elle permet d'accéder aux taux de change et aux conversions sans login utilisateur.

⚠️ Clé confidentielle - Ne pas partager publiquement

Clé API (Tier Standard - 1000 requêtes/heure) :

fxp_XFGShWL3pYRt3wfMf4xLy_1_w9d7doUwImuUsfylQbA

Header à ajouter dans chaque requête :

X-API-KEY: fxp_XFGShWL3pYRt3wfMf4xLy_1_w9d7doUwImuUsfylQbA

🔄 Créer ou régénérer une clé API :

Endpoint de création automatique (protégé par secret) :

GET /api/v1/setup/create-key/?secret=changeme123

Première création : Utiliser l'URL ci-dessus
Régénérer une clé : Ajouter &reset=true

Exemple : https://api-echange.onrender.com/api/v1/setup/create-key/?secret=changeme123&reset=true

📱 Intégration React Native + Expo

Étape 1 : Installer axios

npx expo install axios

Étape 2 : Créer src/config/api.js

export const API_CONFIG = {
  BASE_URL: 'https://api-echange.onrender.com/api/v1',
  API_KEY: 'fxp_XFGShWL3pYRt3wfMf4xLy_1_w9d7doUwImuUsfylQbA',
};

export const API_HEADERS = {
  'X-API-KEY': API_CONFIG.API_KEY,
  'Content-Type': 'application/json',
};

Étape 3 : Exemple d'utilisation

import axios from 'axios';
import { API_CONFIG, API_HEADERS } from './config/api';

// Récupérer le taux
const getRate = async (from, to) => {
  const res = await axios.get(
    `${API_CONFIG.BASE_URL}/rates/${from}/${to}/`,
    { headers: API_HEADERS }
  );
  return res.data.rate.market_rate;
};

// Convertir
const convert = async (from, to, amount) => {
  const res = await axios.post(
    `${API_CONFIG.BASE_URL}/convert/`,
    { from_currency: from, to_currency: to, amount },
    { headers: API_HEADERS }
  );
  return res.data.conversion.converted_amount;
};

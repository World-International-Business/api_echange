📱 Intégration dans l'App Mobile — 3 Étapes
1
Installer axios dans le projet Expo

Exécuter dans le terminal du projet :

npx expo install axios
2
Créer le fichier de configuration API

Créer src/config/api.js :

export const API_CONFIG = {
  BASE_URL: 'https://api-echange.onrender.com/api/v1',
  API_KEY:  'fxp_oNGqt67mlKz40hl0Me748a1rQQwMD0qrjVB1pL16xOY',
};
export const API_HEADERS = {
  'X-API-KEY':    API_CONFIG.API_KEY,
  'Content-Type': 'application/json',
};
3
Créer le service API et l'utiliser dans les écrans

Le code complet de forexService.js et l'écran de conversion sont dans la documentation jointe.

// Exemple d'utilisation dans un écran
import { convertAmount } from '../services/forexService';

const result = await convertAmount('EUR', 'USD', 500);
console.log(result.converted_amount); // "595.53"
console.log(result.market_rate);      // "1.17"

Comment ForexPlatform API garantit des taux de change toujours frais

⚡ Flux Principal (À la Demande)

1
Application Mobile demande un taux
Ex: "Quel est le taux EUR/USD maintenant ?"
📱 App Mobile
2
L'API vérifie le cache Redis
Si le taux a été demandé il y a moins de 5 min → Retourne immédiatement
⚡ Cache Redis
3
Si pas en cache → Appelle les Banques Centrales
ECB (Banque Centrale Européenne) en premier - Gratuit et fiable
🏦 Banques Centrales
4
Sauvegarde et Retourne le taux
Mis en cache 5 min + sauvegardé en base de données
